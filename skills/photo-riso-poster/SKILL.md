# 孔版留白海报

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

从参考照片提取一个主元素与最多两组关系，保留数量、间隔、朝向、遮挡和大小层次，再把它们译为稀疏印刷图形。没有照片时从用户主题提炼一个可见意象，不捏造拍摄日期、地点或档案事实。比例自动时参考原图方向，纯文字主题可用 3:4。

以两到三种有饱和度的墨色制作孔版印刷，细颗粒、轻微洇边和错版叠色清晰可见。冷色照片配浅蓝灰或冷白纸，暖色照片配浅暖白纸，避免发黄污渍。主墨色要实际构成主体，不能退成一个装饰小点。

画面约 65% 至 85% 保持安静纸面，只有一个偏心的小图形簇，不铺满天空、地平线或完整风景。默认保留可辨轮廓；用户要求更抽象时转成点、短线、块与弧；要求更具象时保留印刷插图细节。

文字是可选的证据说明，以小型打字机字或衬线短语贴近图形。数量只写可确认的数量，日期地点只用用户提供的信息。避免卡通、商业大标题、写实光影、三维、霓虹、整页填满和与来源无关的装饰。
