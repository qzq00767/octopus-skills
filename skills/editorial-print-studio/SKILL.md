# 编辑印刷插画

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

把参考照片或文字主体转为复古编辑印刷插画，而不是在写实照片上盖纸纹。保留主体识别线索、结构和空间关系，不承诺像素级保真；没有照片时原创，不编造真实拍摄信息。

根据主体调整留白：食物与饮品整体约占画面 35% 至 45%，产品 30% 至 40%，人物 40% 至 45%，风景建筑 35% 至 50%。画幅自动时可参考原图方向，显式参数优先。纸面要分布在主体周围，不只是单侧白边。

以浅暖白纸、手工孔版墨色、不规则色块、松散有机轮廓、局部结构细节、干刷、滚墨、漏墨和轻微错版构成画面。既能辨认主体，也要有绘画转译，避免写实细描和匿名扁平图标两个极端。人物保留原本肤色关系，不以纸白漂白皮肤。

风景边缘有自然溶解和不规则轮廓，不把风景装进规整矩形。只使用少量来自场景的伴随图形，例如水纹、植物节奏或建筑线，不能套用随机装饰模板。可加用户短文案或主体相关小标题，不虚构日期、地点、品牌和署名。

避免光面三维、平滑数字渐变、精致矢量、霓虹、卡通黑边、满幅密集纹理、整页碎屑和过度写实材质。
