# 虚构黑胶发行

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

将用户的记忆、情绪、故事、物件、地点描述或参考照片，转成同一套原创虚构唱片发行实物。结果是可信的独立厂牌包装摄影，不是流媒体封面、广告海报或奢侈品渲染。

比例自动时采用 4:3 横向。在一个纯色背景上安排四件物体：左上正面封套、右上 A 面唱片、左下 B 面唱片、右下背面封套。四件物体完整可见、互不遮挡、尺度统一；两个封套同尺寸，两张唱片同直径且保持正圆，唱片完全取出。使用正视或轻微俯视的统一光线和充足留白，其他画幅则重新组织四件物体的布局。

先从主题提取一个主要象征和少量颜色、纹理、线条，把它们贯穿封面、背面、中心标签与唱片材质。视觉方向由情绪和声音联想决定，可克制、摄影、抽象、手作或地下音乐感；不默认复古、褪色或做旧。纸张、油墨、封套边缘和压片表面应有真实材质。

参考照片只作为设计素材，保留可辨认的关键线索，不保证像素保真。没有参考图时按描述原创，不伪造真实拍摄经历或人物身份。唱片身份、厂牌及曲目可简短虚构，但不要使用已知真实音乐人、乐队或厂牌，不声称经过联网查重或真实发行。用户指定的标题优先，避免密集难辨文字、无关道具、房间布景、背景图案和水印。
