# 群像剪影拼贴

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

以同一群体和连续环境制作上下双联画，让正负形互换成为主视觉。参考照片存在时优先保留人数、左右顺序、远近尺度、动作、服饰、牵手和持物等关系。此网页版本是生成式风格改编，无法保证人物像素或身份细节完全不变。没有参考照片时按文字原创，不声称保留真实原片。

自动比例可用 4:5 或 2:3。上半部展示摄影感场景，并用纸色剪影覆盖部分区域；下半部铺纸色，以对应位置的剪影孔洞露出同一场景，形成明显的形与底互换。横向排队群体可用连体纸人形，错落群体可用相互呼应的独立剪影。

用一种主要纸色、一种小面积强调色和照片自然颜色，纸色约占全页 40% 至 60%。纸张有纤维与墨色变化，摄影区域保留自然颗粒感；边缘略不齐，有手工剪裁感，避免抛光矢量蒙版。

可在接缝附近加入一条与场景相关的短手写句，以及少量松散手绘星号；用户要求无字或简洁时减去。不要遮挡脸、手、重要物件，不新增人物肢体，不把双联画变成贴纸堆、照片网格或满页装饰。
