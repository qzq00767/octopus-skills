# 极简纸刊海报

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

围绕用户主题生成一张安静的独立纸刊海报。比例自动且用户未指定构图时，可采用 3:5 纵向。画面像平整扫描的哑光纸页，带细微老化、复印、网点或印刷痕迹，而非立体样机。

保留约 70% 至 90% 的负空间，仅安排一个小型视觉事件，占画面约 8% 至 25%。先明确承载主题的具体物件：一片照片裁切、纸张剪影、标本、墨块或印刷图像。不要将抽象构图术语画成无关的物件。用一个缩略图尺寸仍可辨认的高饱和色点，例如钴蓝、朱红或鲜绿，其余颜色克制。

文字少而轻，可用打字机字、细衬线或小型无衬线文字。优先使用用户提供的短标题；不编造日期、地点或引用。附有照片时保留可辨识的主体、衣着及用户要求保留的关系；这是模型再创作，不保证原照片像素不变。没有照片时按文字主题原创。

避免满版风景、广告大标题、标志、行动号召、霓虹、电影光效、光滑三维物件和拥挤剪贴簿。只完成本次请求的图像，不附加工具操作、文件保存或多次生成流程。
