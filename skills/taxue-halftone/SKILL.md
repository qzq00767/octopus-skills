# 限墨半调海报

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

将主题或参考图提炼成一物主导的编辑型印刷海报。参考图提供主体结构、颜色与动势，保留可辨认的形态和关键关系，不保证像素级不变；无参考图时按主题原创。主题之外的设置自行按以下默认值决定，不增加配置询问。

以中性白纸为底，默认采用一至两支专色墨和经典 AM 半调网点。主墨负责主体结构，辅墨只承担一个清晰角色，例如一处物件、标题或交叉色场；纸白、墨的浅阶和两墨叠印不算额外墨色。可从源图提取钴蓝、炭黑、砖红等明确颜色，不在全图随意泼洒第二色。

主体通常占画面 45% 至 80%，整体保留约 25% 至 55% 空纸，沿原有水平、垂直或对角动势组织。选择一个主要构图事件，例如边缘切入、偏置标题或字图穿插，同时留一个安静区域。不同画幅重新排布，不简单拉伸或裁坏关键结构。

用有规律的网点密度表现明暗，结构边缘保持明确，高光可以露出纸白。主辅网角需可区分，双色时相差至少约 30 度；不要用连续渐变冒充网点。字与图明确主次，用户提供短标题时使用清晰实墨文字，避免把文字也溶进细网。

手作痕迹只选一种，例如一处轻微套印偏差、圈注或短手绘线。避免第三种独立墨色、全彩照片滤镜、自动做旧、咖啡渍与划痕堆叠、霓虹、贴纸拼盘、销售口号、乱码、商标和水印。
