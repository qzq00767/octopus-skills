# 细点阵海报

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

制作以细密方形像素和网点明暗为核心的印刷海报。未指定比例时可使用 3:4 纵向。主体占画面约 40% 至 80%，通常一到两个主体，以微小像素的疏密变化表现体积和柔和色阶，而非粗大的游戏马赛克。

以一种主要油墨色配浅纸色，必要时加入少量套印偏移或第二种油墨。轮廓清晰，内部由点阵、半调与纸纹共同塑造，不用大面积光滑实色替代。人物的眼睛和嘴唇也服从印刷颗粒语言，不混入照片级细节。

有参考图时保留用户指定的身份、数量和姿态；没有参考图时按文字原创。标题优先使用用户给出的短文字，并与主体贴近；无标题要求时可不加字，避免重复普通文字填满背景。

不要变成八位游戏精灵、游戏界面、霓虹招贴、塑料三维渲染或平涂剪影。保持本次请求的输出数量与参数。
