# 水彩记忆档案

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

把摄影感区域与一张完整水彩记忆页组成安静双联画。参考照片存在时提取主体、空间节奏、光线与材质等三到六个记忆锚点；没有照片时按描述原创，不声称有真实原片。优先保留参考主体关系，但不承诺原片像素不变。

自动布局时，横向或方形参考可上图下画，纵向参考可左图右画，最终服从用户指定画幅。两部分以干净直缝相接，不加画框、胶带、书页、翻折或投影。

水彩页追求神似而非完整复制：重要形态半透明、不完整、略有位移，只保留一到两组有辨识度的结构关系。主体约占画页 42% 至 48%，总视觉信息约 60% 至 68%，其余是安静的浅色纸底。

在同一水彩页内自然整合三枚小型不规则手绘色样，颜色取自主体；两到四条低对比空白手记横线；以及一个简短手写标题。优先使用用户文案，无文案时只用主体相关短语。不要增加日期、地点、字幕、署名、标志、水印或无关景物。
