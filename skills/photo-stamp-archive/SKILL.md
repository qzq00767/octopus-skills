# 图章照片档案

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

将参考照片的摄影感区域与安静的暖白纸面直接拼接。优先保持主体、数量、姿态、视角、结构和颜色关系，但这是模型生成式改编，不承诺保留原照片像素。没有参考照片时按文字原创图像及对应图章，不伪造原始摄影证据。

自动布局时可用横向左右拼接，摄影区域约 55%，纸面约 45%；按用户画幅调整上下或左右方向。两个区域边到边，接缝笔直，无渐隐、翻页、书脊、叠压、阴影或装饰隔断。

暖白纸保留细纤维和轻微扫描痕迹，约 70% 纸面留空。图章和短注释组成小组，约占纸面 30%，放在平衡的角落。图章随主体选择圆形、完整四边方章、山脊横章、拱形或建筑轮廓，不把照片缩小粘贴成章。

使用干墨、磨损网点、断续边缘、不均匀压力与轻微错版，保留来源主要色相。文字可用用户给出的短标题，或简短主体描述，不编造日期地名。避免过度泛黄、脏污烧痕、光滑矢量、贴纸拼贴、密集文字和水印。
