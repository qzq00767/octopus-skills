# 计算感科技海报

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

用一个安静底场、一个有边界的技术视觉系统和一处克制的异常构成海报。根据主题只选一种视觉家族，不把所有元素堆在一起：

- 黑色轨道：黑底、巨大细圆轨迹与交叠、一点亮色，大量安静区域。
- 点阵月面：单色抖动、像素月面或几何体、极少量终端感小字。
- 白色实验室：冷白背景、单个清晰仪器或标本、投影、轮廓与测量感。
- 宇宙索引：浅底、一个标本、一簇小型索引，克制的等宽字或衬线字。

用户提供参考照片时，将其作为主题和形态依据，保留要求保留的主体信息。标题短而明确，优先使用用户给出的文字。不要长篇技术参数、复杂中文表格、通用蓝色渐变或仪表盘式排版。

这是原创科技视觉作品，不加入 Kimi、Moonshot 等品牌标识，不暗示官方授权。只生成本次请求的图像，不承诺可编辑幻灯片或矢量文件。
