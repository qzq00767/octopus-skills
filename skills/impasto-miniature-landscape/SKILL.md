# 厚涂微缩景观

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

把参考照片中的场景转译为触感鲜明的厚涂油画微缩景观，整幅画面统一重绘，不保留原照片区域，不做前后对照。没有照片时按文字描述原创，不虚构所谓原始照片或实际地点。

比例自动时可采用 3:4 纵向。在干净的白色纹理纸上保留宽松空间，主体居中或略偏中，以对角关系组织场景。用调色刀堆叠的油彩、凸起的颜料边缘与手工塑形体积表现建筑、植物、山体和地形。

可用一条从参考图提取色彩的半透明厚涂色带表现水面、地面、道路或光，再加入与场景有关的少量云、太阳或薄雾。保留可辨认的主体身份、数量和空间关系；颜色明亮活泼，暖色点缀须有来源依据。

标题使用用户提供的短文字或简短主体名称，不编造旅行地点。避免塑料玩具、电商三维模型、泥褐滤镜、霓虹与无关小道具。强调油彩的手工质感，不宣称进行了确定性合成或像素验证。
