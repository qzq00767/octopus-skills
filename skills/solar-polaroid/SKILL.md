# 节气拍立得

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

把用户提供的节气、季节短句、节日、地点记忆或照片变成有主题依据的纸本编辑视觉。默认直接生成最终图片，不先输出创作方案，不要求用户配置参数。自动比例时偏好 3:4；用户选择的比例和张数优先。

## 从主题建立画面

先在内部确定主题发生的变化、可见物证、一个主导动作、空间关系、材料和少量文字。用户照片和明确提供的地点、时间、物件优先；未提供的天气、日期、身份不能伪装成事实。节气的常见物候只作创作线索，不硬编码某片叶子、固定色卡或固定日期。

默认混合纸本档案结构：外部底纸、暖白档案卡、卡内图像窗口、一个越界的核心形态、由大到小的信息层级。卡片位置、窗口横竖、颜色、越界方向应由主题决定。纸张有可信材质，阴影是轻浅接触影；避免厚重悬浮卡片和毫无意义的红点、印章、几何角标。

照片窗口表达与主题同源的可见物证，例如雨后的湿伞、晚饭后的空杯、刚熄灭的蜡烛，而不是用无关装饰填空。一个核心物件或形态跨越窗口或卡片边缘，使纸张和内容产生真实遮挡。

## 用户指定时切换路线

- 拍立得、街拍、生活摄影：使用即时成像的现场光、近距手持透视和自然显影质感；文字仅在相纸白边，窗口内无可读中文，不强制档案拼贴。
- 开放、概念、实验、不要模板：由主题动作组织空间，可放弃卡片结构，不重复同一套“白卡加叶子”。
- 系列、固定框架：保留纸张与信息层级，每张改变物证、视角、窗口方向或越界关系，不仅换色。

## 文字与交付

精确文字逐字沿用用户输入。默认只用简短标题与一条来自画面证据的自然观察，例如“伞沿还在滴水”。用户要求无字则全部省略。没有提供的日期、地址、品牌、署名和引文不添加，也不默认印上原作者的署名。

直接生成最终图片，不把分析、真实性注释、参考文件路径或后续操作指南画进作品。
