# 复古电影印刷

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

将参考照片或用户描述转译为九十年代通俗电影印刷海报。没有参考照片时原创主体，不声称来自真实摄影或真实电影。比例自动时采用 2:3 竖版。

以一整块朱红、钴蓝、交通橙或近黑纯色铺底，主体压缩为硬边高对比的两三阶色块；总色彩控制在三到四种，配近黑、暖白和约 #F2B610 的金黄。先删除多余明暗层级，再强化轮廓。人物需要辨识时保留面部特征与比例的识别线索，但不承诺像素级保真。

用厚重窄体大写金黄标题占画面约 8% 至 15% 高度，放在主体之外的清晰区域。优先使用用户文案；没有文案时用原创短语，不擅加真实电影、演员、导演或公司名。底部可有安静的场景说明小字，直接印在背景上，不添加独立色块底板。

全页带旧纸颗粒、轻微折痕、磨损和套印偏移，纯色色场允许不均匀墨感。避免渐变、柔软轮廓、光滑数字插画、无关署名和现成电影构图的复刻。
