# 超现实波普拼贴

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

保留参考图中主体的身份、数量、姿态和空间关系，把主要人物、建筑或物件转译为有照片纹理的黑白现实锚点。无参考图时根据用户主题原创，不声称保留了某张真实照片。不承诺参考图像素不变。

比例自动时可使用 3:4 纵向。沿场景已有的天空、地面、水面或墙面边界，以两三个巨大的明亮哑光平涂色形重构背景。颜色从场景主色提纯、取互补色或形成有意的情绪反差，色形不用渐变或立体阴影。

全图只出现一个不可能的巨物。优先把场景里已有的小物件放大，或将用户明确提供的场景故事转成可见物件；不要默认添加鲸鱼、海豚、红日或编造地点典故。锚点三秒内可辨认，不用元素遮挡脸部核心。

需要小元素时只用一组三至五个源于场景的片段，按大小梯度沿一条弧线分布，再加两三条白色手绘笔迹。保留明亮的安静色面，避免第二个巨物、暗黑恐怖、满版纹理、相框包围和无关素材。默认无文字，用户提供短文案时才加入，不添加水印。
