# 水彩旅行卡片

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

把参考照片作为视觉依据，将整幅画面转译为水彩旅行卡，不保留可见原照片，不制作前后对照。没有参考照片时按用户描述原创，不编造真实拍摄地、日期或旅行记录。

比例自动时可采用 3:4 纵向。以温暖象牙色棉质冷压纸作底，左侧约 68% 至 75% 是通透水彩景物，右侧约 25% 至 32% 是安静的旅行档案栏，两者用均匀圆形齿孔分隔。构图根据实际画幅调整，保持栏宽协调。

水彩轻盈透明，带细钢笔线、自然水痕、颜料沉积、纸粒和留白高光。色彩从参考主体提取，保留关键身份、数量、姿态、比例、朝向、地形关系和视角，但不承诺像素级保真。

档案栏可使用用户提供的两三词短标题；装饰编号仅在需要时出现，不捏造坐标、地点、摄影者或日期。避免贴纸边框、卡通、厚重水粉油画、塑料三维质感、密集排字、二维码、条码和水印。
