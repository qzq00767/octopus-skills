# 纸上留影

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

有参考照片时，让上部摄影区域与下部温暖纸色的记忆版画呼应。摄影区域以所附照片为依据，尽量保留主体、光线、结构、空间关系和视角；生成式处理不能保证像素不变，不冒充未经修改的纪实原片。

下部提取一个仍能认出来源的主体轮廓与光影关系，用平面墨块、负空间切口和少量短线压缩表达。保留让主体站得住的地面、道路、水平线或尺度线索，不能简化到只剩无意义的色块。采用深蓝、黑、灰绿或青色，必要时取照片中有依据的一处暖色。

纸张肌理细腻，留白宽松，构图安静。可放一个用户提供的短标题，未要求时可不加字。不画水彩复刻、弥散雾团、杂乱几何样本或装饰边框。

没有参考照片时，仅根据文字生成纸上版画，不伪造所谓原照片或真实拍摄地点。只生成请求的作品，不宣称执行照片合成或像素核验。
