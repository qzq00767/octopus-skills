# 城市微光夜景

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

把参考环境照片或文字场景重构为真实材质的夜景，环境是主角。比例自动时可采用 9:16。参考照片存在时保留两到四个地点识别锚点，如道路弯向、建筑轮廓、树线和港口关系；没有照片时按描述原创，不虚构真实地理记录，不承诺像素保真。

选择一对有明显对抗关系的灯光：钠黄对深青绿、信号红对冷青蓝、暖白对石油蓝，或品红对冷绿。环境色面积较大，集中光源更小更亮；暗部保留结构。让环境色落在建筑、路面、玻璃或水面等至少两种真实载体上，不把画面简单染成两色滤镜。

用城市光污染、工业薄雾或室内湿润空气建立纵深。按场景选择干雾、雨后、正在下雨、水岸或凝露，雨后湿地不等于正在落雨；反射要断续并对应真实光源，不强制每张图加雨。

可将用户短文案放在合理的灯箱或建筑标识上。没有文案且允许文字时使用一个原创双词短句；用户要求无字时不新增文字。保留日常尺度与摄影材料感，避免未来巨构、全屏霓虹、主角人像、塑料三维质感、死黑天空与过度锐化。
