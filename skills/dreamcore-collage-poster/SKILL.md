# 梦核拼贴海报

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

生成浓密、满版、多层的梦核拼贴，比例自动时可采用 3:5 纵向。用一个约占画面 50% 至 75% 的可辨认主体作锚点，再加入两至五个有关联的细节裁切、镜像、重复或异常尺度碎片。

附图时让环境与碎片来自原图中的主体、情绪和线索，保留用户要求的身份特征；无图时根据主题原创。画面应有一处明确的超现实异常，例如尺度错位或不可能的空间连接，而不是无关素材堆积。

用两至四种有意选择的主色，加入半透明几何遮片或伪窗口，以及扫描线、网点、低保真压缩、像素退化或复印纹理。纹理服务空间层次，不能让主体无法辨认。

避免极简大留白、广告层级、冗长文字、真实商标、水印及光滑三维效果。只执行本次图像请求，不自动扩展为多轮生成或外部处理。
