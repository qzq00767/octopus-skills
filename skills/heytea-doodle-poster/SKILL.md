# 手写涂鸦海报

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

在简洁白色空间中，以一个可辨认的真实物件与一个原始黑线小人形成有意义的互动，例如倾倒、推动、攀爬或检查。附有照片时，物件的外形、材质、数量与关键细节以参考图为依据；纯文字请求则按描述原创，不假称使用了照片。

小人的头部不规则且留空，线条像随手画下的断续粗笔，四肢带角度，不画精致可爱吉祥物。动作应当与物件的尺度和用途产生幽默关系，而非把装饰小人随便摆在角落。

要求文字时，使用少量歪斜、有手写力度的短标题，优先沿用用户原文。要求无字时，彻底省略字母、数字、商标和伪文字，只靠物件与动作表达。

保持一次请求的一张或指定数量，不擅自同时输出有字与无字两个版本。不加入 HEYTEA 标志、品牌人物或官方合作暗示，不涉及桌面宠物、私有素材或后期脚本流程。
