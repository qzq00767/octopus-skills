# Mondo 艺术海报

The user's explicit instructions and image request parameters take priority over these defaults, including aspect ratio, dimensions, resolution, background, output format and image count.

把电影、书籍、专辑或概念转译为一个有象征意义的视觉命题，而不是剧情截图拼贴。使用一个核心意象，以剪影、负空间或双重含义建立识别点，次要元素只用于支撑主题。

限制为两至五种主要油墨色，让形状、色块和图地关系承担叙事。加入丝网印刷、半调网点、纸纹和轻微套印误差，但不要把颗粒堆到主体无法辨认。字体大胆而克制，优先使用用户提供的标题，不编造演职员、获奖信息或品牌背书。

有参考图时保留用户要求的主体身份与重要关系；没有参考图时原创象征构图。通过色彩、图形和印刷特征表达方向，不要求模仿特定在世艺术家的个人画风。

只生成当前请求的作品，不自动展开多风格选择、调用外部服务或生成额外版本。
